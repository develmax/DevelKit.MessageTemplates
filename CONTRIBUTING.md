# Участие в разработке

Для изменения кода создайте ветку и pull request с описанием проблемы, ожидаемого поведения и выполненной проверки. Публичные обсуждения ведутся через GitHub Issues.

Перед отправкой выполните ./build.ps1 на Windows с PowerShell 7, .NET SDK 10 и .NET Framework 4.8. При исправлении поведения добавьте воспроизводящий сценарий в tests/Regression или tests/DynamicsCrm.Regression. Для документации достаточно проверить примеры и ссылки.

Ядро собирается для net452 и net10.0. Сохраняйте совместимость обеих платформ. CRM-адаптер использует SDK 2015, SQL-адаптер зависит только от ядра. Не добавляйте прикладные схемы, адреса инфраструктуры, учётные данные и реальные клиентские данные.

При изменении грамматики согласуйте парсер, дерево, форматтер, построение запросов и docs/syntax.md. Даже небольшое изменение обработки null или числовых типов может менять существующие сообщения.

Код проекта распространяется по MIT. Предлагая изменения, сохраняйте условия этой лицензии и существующие уведомления об авторских правах.
