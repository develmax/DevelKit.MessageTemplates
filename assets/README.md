# Project icon / Иконка проекта

- icon.png: 128 × 128, embedded in every NuGet package.
- logo.png: 512 × 512, used in the repository README.
- icon-source.png: original generated artwork.

Created with the built-in imagegen tool. Production exports are scaled from the original without changing the design.

Design prompt: A professional developer-library icon for DevelKit.MessageTemplates. A cyan and turquoise message bubble between white curly braces on a deep navy rounded-square background. Crisp geometry, no lettering, ample margins, readable at small sizes.

The artwork is distributed under the repository's MIT license.
