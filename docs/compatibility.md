# Поведение и совместимость

**Русский** | [English](https://github.com/develmax/DevelKit.MessageTemplates/blob/main/docs/en/compatibility.md)

## Основное поведение

- Синтаксис {{entity:field}}, {{entity:field(format)}} и {{entity:relation{{other:field}}}}.
- Условия if[[field operator literal ? field ; field]], включая вложенные условия и переходы.
- Операторы =, !=, <, >, <=, >=. Литералы: строка, неотрицательный Int32, true, false, null.
- Положение параметра в исходном тексте, обратные ссылки Parent и дерево SubParameters.
- Нераспознанные конструкции обычно остаются обычным текстом. Validator проверяет дерево, а не полноту синтаксического разбора.
- При null удаляются все предшествующие пробельные символы буфера, включая переводы строк. Последующие пробелы остаются.
- Равенство через CLR Equals: Int32 и Int64 с одинаковым значением не равны. Упорядоченное сравнение требует совместимых числовых типов.
- Дубли имён псевдонимов: последнее определение побеждает. Поиск без учёта регистра, один проход, неактивный псевдоним удаляется.
- Общие связи и колонки объединяются, узлы текста сохраняют отдельные отображения.
- Обе ветви условия входят в план чтения. Форматтер выбирает одну ветвь.
- Одна строка результата, без агрегирования и коллекций.

## Устройство текущей версии

- Пространство имён ядра: DevelKit.MessageTemplates.
- Null-текст можно передать и парсеру, и форматтеру: итог пустой.
- Глубина разбора поля ограничена 64; превышение вызывает FormatException.
- Метаданные и связи задаются IQueryMetadata, включая цепочки с промежуточной таблицей и фильтрами.
- Идентификатор корня — object: допускаются значения не только Guid.
- Нет корневого target или строки данных — InvalidOperationException.
- ITemplateDataProvider возвращает plain CLR values, без обязательных специфических обёрток.
- Нормализация и часовые пояса вынесены в приложение/transform.
- Генератор SQL Server: нет фиксированного имени базы, нет изменения дерева при генерации, фильтры квалифицированы псевдонимами, значения передаются DbParameter.
- NOLOCK по умолчанию отключён. Если QueryExpression.NoLock включён явно, SQL-генератор добавит его.
- Кеш использует SemaphoreSlim, делегат Func<DateTimeOffset>, настраиваемый TTL и поколение инвалидирования. Отдельная внешняя библиотека блокировок не нужна.
- Невалидное имя определения псевдонима вызывает ошибку целиком.

## Границы версии

- Ядро: net452 и net10.0. CRM-адаптер: net452 и SDK 7.0.0.1; SQL-адаптер: net10.0. CRM-сценарии проверены локально на совместимом .NET Framework с тестовым IOrganizationService, без живой CRM.
- Культура форматирования — CurrentCulture. Автоматического определения часового пояса нет.
- Нет HTML-кодирования: приложение должно выбирать кодирование для контекста вставки. Подходит для текстов; готовым безопасным HTML-движком пакет не является.
- Нет строгого синтаксического режима. Большое число в условии может вызвать OverflowException; вложенность ограничена, но общий лимит длины и времени разбора не задан.
- Удвоенные одинарные кавычки в строковых литералах сохраняются удвоенными. Отрицательные и дробные литералы не поддержаны.
- SQL-генератор поддерживает SQL Server, равенство в фильтрах, AND/OR и INNER/LEFT JOIN. Это не полный ORM и не совместимый клон CRM QueryExpression.
- TOP 1 без ORDER BY не определяет устойчивый выбор в отношениях один-ко-многим. Метаданные приложения должны обеспечивать однозначность.
- Есть отдельный CRM SDK-провайдер; выполнение SQL остаётся в приложении. Нет редактора шаблонов, REST-хоста, отправки сообщений и правил SMS/Email.
- Публичные модели дерева изменяемые. Не изменяйте дерево во время рендеринга и не делите изменяемый план между конкурентными операциями.
- Метаданные должны ограничивать поля и связи. Проверка SQL-идентификаторов не заменяет контроль доступа.
## Кеш и CRM-адаптер

CachedTemplateAliases принимает делегат clock для управляемого времени. TemplateSchema задаёт явный список допустимых сущностей, полей и связей. Завершайте настройку до конкурентного использования.

CRM-адаптер преобразует нейтральный план в SDK QueryExpression и разворачивает AliasedValue, OptionSetValue, Money и EntityReference в CLR-значения. RetrieveMultiple синхронный: отмена проверяется до и после вызова, но не прерывает выполняющийся запрос. Адаптер не владеет переданным сервисом. Развёртывание в CRM и совместимость с современным Dataverse не проверялись.
