# Как читать код шаблонизатора

**Русский** | [English](https://github.com/develmax/DevelKit.MessageTemplates/blob/main/docs/en/code-guide.md)

Начните с [примера без базы](../samples/Meetings/Program.cs) или [примера CRM SDK](../samples/CrmMeetings/Program.cs). Затем откройте TemplateEngine.RenderAsync: в нём видна вся последовательность подготовки текста.

## Основной путь

1. TemplateAliases.Expand раскрывает короткие имена из каталога в технические выражения за один проход.
2. TextTemplateParser.Parse строит дерево и сохраняет координаты параметров в исходной строке. ParseWithRevert возвращает позицию после неудачной попытки разбора.
3. TextTemplateValidator.Validate проверяет распознанные узлы. Неизвестный синтаксис может остаться обычным текстом.
4. TextTemplateQueryBuilder.Build объединяет колонки и одинаковые пути связей. TemplateMapping сохраняет связь каждого вхождения с колонкой результата.
5. ITemplateDataProvider.ReadAsync возвращает одну строку по плану. Корневые поля имеют ключ вида field, связанные — alias.field.
6. TextTemplateFormatter.Format копирует текст между параметрами, вычисляет условия и выводит готовые значения.

## Где находятся решения, которые легко пропустить

- В парсере if имеет три дочерних узла в фиксированном порядке. Вложенная связь содержит один дочерний параметр.
- В построителе фильтры участвуют в сравнении связей. Иначе разные роли участника могли бы попасть в один переход.
- Обе ветви if загружаются заранее. Условие выбирает выводимое значение, а права чтения задаёт приложение.
- Форматтер удаляет пробелы слева от null. Он не исправляет пунктуацию и не выполняет HTML-кодирование.
- CachedTemplateAliases запоминает поколение до загрузки: сброс во время чтения не потеряется.
- CrmQueryTranslator создаёт настоящие типы SDK. CrmTemplateDataProvider раскрывает обёртки значений; сам вызов CRM 2015 синхронный.
- SQL-генератор оставляет фильтр связи в ON и передаёт значения через DbParameter. Проверка имени колонки не заменяет разрешение на её чтение.

Эти решения пояснены комментариями рядом с соответствующими участками. Для основных публичных контрактов добавлены XML-комментарии; XML-файлы документации генерируются вместе со сборками и включаются в пакеты для подсказок IDE.
