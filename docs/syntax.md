# Синтаксис и обработка

**Русский** | [English](https://github.com/develmax/DevelKit.MessageTemplates/blob/main/docs/en/syntax.md)

## Параметры

```text
{{person:name}}
{{meeting:startsAt(dd.MM.yyyy HH:mm)}}
{{meeting:guest{{person:name}}}}
{{meeting:if[[isOnline = true ? meetingUrl ; address]]}}
```

Параметр начинается с имени сущности. После двоеточия записывается поле или if. Вложенный параметр описывает переход по связи. Круглые скобки задают формат .NET для значения конечного поля.

if сравнивает значение поля с литералом и выбирает одну из двух ветвей. Ветви содержат поля, переходы по связям или следующие условия. Они не допускают произвольный C# и строковые константы вместо поля. Доступны сравнения =, !=, <, >, <= и >=. Новые операторы, арифметика, циклы и вызовы методов не поддержаны.

## Грамматика EBNF

Здесь ::= задаёт правило, | разделяет альтернативы, ? означает необязательную часть, * любое число повторений, + хотя бы одно. Строки в кавычках являются терминалами.

```ebnf
Parameter ::= "{{" S Name S ":" S Field S "}}"
Field     ::= If | Name S (Parameter | Format)?
If        ::= "if" S "[[" S Condition S "?" S Field S ";" S Field S "]]"
Condition ::= Field S Operator S Value S
Operator  ::= "!=" | "<=" | ">=" | "=" | ">" | "<"
Value     ::= String | Integer | Boolean | Null
Boolean   ::= "true" | "false"
Null      ::= "null"
Name      ::= NameChar+
Integer   ::= Digit+
String    ::= "'" (StringChar | "''")* "'"
Format    ::= "(" FormatChar+ ")"
S         ::= (#x20 | #x9 | #xD | #xA)*
```

NameChar соответствует char.IsLetter, char.IsNumber или подчёркиванию. Digit соответствует char.IsDigit. StringChar допускает любой символ, кроме одинарной кавычки. FormatChar допускает любой символ, кроме круглых скобок. S содержит пробел, табуляцию и переводы строк. Имена проверяются отдельно по разрешённой схеме.

Учитывайте поведение реализации:

- Имена могут начинаться с цифр. Ключевые слова чувствительны к регистру.
- Число преобразуется через int.Parse. Отрицательные и дробные значения не поддержаны. Переполнение вызывает исключение.
- Пустая строка разрешена. Удвоенные кавычки внутри строки остаются удвоенными.
- Пустой формат и скобки внутри формата не поддержаны.
- if распознаётся раньше обычного имени. Длинные операторы проверяются раньше коротких.
- Парсер допускает Field слева от сравнения, но форматтер не вычисляет вложенный if в этой позиции. Используйте там поле или путь к полю. Вложенные условия в ветвях вычисляются рекурсивно.
- Глубина разбора ограничена 64.

Это грамматика распознаваемого параметра. Исходный текст сканируется слева направо. При неудачной попытке разбора курсор возвращается, а сканирование продолжается. Нераспознанные части сохраняются как текст. TextTemplateValidator проверяет построенное дерево, поэтому не заменяет строгую проверку исходной строки.

## Каталог именованных параметров

TemplateAliases.Expand заменяет короткие ключи вида {{meeting:date}} полными выражениями из каталога. Ключ соответствует {{entity:field}}, обе части содержат символы regex \w. Вокруг частей разрешены пробелы, внутри имён пробелы не допускаются. Названия для пользовательского интерфейса приложение может хранить отдельно.

Поиск не учитывает регистр. Последнее определение имени побеждает, неактивное определение заменяется пустой строкой. Раскрытие выполняется один раз: вставленные определения повторно через каталог не проходят.

CachedTemplateAliases загружает определения через ITemplateAliasRepository, поддерживает TTL и Invalidate. Переиспользуйте экземпляр кеша. Вызовите ExpandAsync до передачи результата в TemplateEngine.
